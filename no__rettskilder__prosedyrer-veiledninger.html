    Internett Explorer

    Velg fanen Vis → Skalering → Velg Større eller Mindre skrift.
    Opera
    Velg Opera-ikon → Side → Zoom → Velg størrelse.
    Chrome
    Velg Verktøy-ikon → Ved Zoom, klikk + og -.
    Safari
    Velg Side-ikon → Zoom → Velg Zoom inn eller Zoom ut.
