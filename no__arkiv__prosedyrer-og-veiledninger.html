  • For å justere tekststørrelsen, bruk nettleserens innebygde zoomfunksjon. Skriftstørrelsen kan da økes med hurtigtastene Ctrl++ og reduseres med Ctrl+-.

    Alternativt

    Internett Explorer
    Velg fanen Vis → Tekststørrelse → Velg en av de tilgjengelige størrelsene.
    Mozilla Firefox
    Velg fanen Vis → Skalering → Velg Større eller Mindre skrift.
    Opera
    Velg Opera-ikon → Side → Zoom → Velg størrelse.
    Chrome
    Velg Verktøy-ikon → Ved Zoom, klikk + og -.
    Safari
    Velg Side-ikon → Zoom → Velg Zoom inn eller Zoom ut.
